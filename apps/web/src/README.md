# src

- `main.tsx` — mounts the application and applies the stored language and theme.
- `app/` — router, providers, layout and preferences.
- `api/` — the typed HTTP client and the query hooks.
- `i18n/` — the English and Spanish catalogues and the formatters.
- `theme/` — design tokens, base styles, fonts and the AG Grid theme.
- `assets/` — the cover photograph and its credit.
- `components/` — shared pieces: probe, big figures, thinking bar, icons, settings.
- `features/` — one folder per screen, plus the PayPal checkout and the guide they share.

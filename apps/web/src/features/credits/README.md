# credits

The page `/credits`, "Credits and sources": the only place where Rewire credits what it uses.

- `CreditsPage.tsx` — every official data source with publisher, version, licence, retrieval date,
  the literal attribution and, when the licence asks for it, the adaptation notice; where the
  listed courses come from, with each citation and date as the server reports them; the credit of
  the cover photograph; and the note that each library document belongs to its publisher.
- `Credits.module.css` — the list of sources and their facts.

# privacy

The page `/privacy`: the only place where Rewire says what it keeps and what it does not.

- `PrivacyPage.tsx` — what is kept and what is not, where the words written to Rex or Tempo go
  (the provider and whether it may learn from them, as the server's configuration says) and what
  happens to an employer's email at payment. Fields that write to a model link here.
- `Privacy.module.css` — the measure of its paragraphs.

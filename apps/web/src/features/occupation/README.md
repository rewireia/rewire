# occupation

Confirming the occupation the search found, before the report.

- `ConfirmPage.tsx` — reads the address and loads the occupation by its code.
- `ConfirmOccupation.tsx` — the occupation, the international group it is read through and why, and
  the main action, which saves the learner's profile before opening the report.
- `GroupTasks.tsx` — the tasks of that group, without scores, to compare with the person's work.
- `Alternatives.tsx` — other groups the occupation is linked to; choosing one shows its tasks.
- `match.ts` — the groups an occupation can be read through.
- `links.ts` — the addresses of the confirmation page and the report.

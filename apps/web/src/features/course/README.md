# course

A course of the demonstration catalogue and the two ways to pay for it.

- `CoursePage.tsx` — the course, PayPal checkout or, when enrolled, the way back into it.
- `CourseFacts.tsx` — step, level, length and what the learner will be able to do.
- `EmployerRequest.tsx` — the region's case for an employer paying, quoted with its source, and
  the form that sends a PayPal invoice. The employer's address is not kept.

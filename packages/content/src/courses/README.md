# content/src/courses

The courses of the learning plan: real free courses run by others, and the demonstration
catalogue of paid courses.

```text
courses/
├── free.ts          FREE_COURSES, each with the day its link and its "free" claim were checked
├── demo/            the paid demonstration courses, one file per course
├── listed/          real courses of other providers that the marketplace lists; see its README
├── topics.ts        the subjects of the catalogue, with their English and Spanish labels
└── hosted-topics.ts the subjects of each demonstration course
```

## Rules

- A free course is linked, never copied: see the package README for what is listed and how a
  link is reviewed.
